# Silver Lantern 1.4.0

- **One executable:** Open `SilverLantern.exe` for the controller-first launcher, or use `--cli` for console mode.
- **One-click setup:** The default flow checks for updates, installs approximately 33 GB of prebuilt game files with cleanup, applies a GPU preset, and launches. Allow at least 40 GiB of free space for the preflight check.
- **Updates:** The launcher can update the tool automatically, and game updates download changed files rather than rebuilding everything. The automatic restart now preserves the correct arguments.
- **Also included:** Resumable downloads, clearer progress and error messages, and optional classic builder, preset and game-update tools from the 1.3.x releases.

# Silver Lantern 1.4.0

## What's new

- **One-click installation:** Extract the release ZIP and open `HeyListen-Get.exe`. The game installs from ready-made files and opens automatically when it is ready.
- **Automatic updates:** The tool and game check for updates on the next run and download only what changed. Nothing is recompiled on your PC.
- **Clearer progress and errors:** Follow the download on one progress line, with friendlier messages if something goes wrong. An interrupted download can resume.
- **Restart fix:** The tool now handles restarting after an update more reliably.
- **Game files release:** Ready-made game files are available for the new installation experience.
